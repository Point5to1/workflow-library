# Workflow Library

**Part of [Point5to1™](https://github.com/point5to1)**

*Map the work. Redesign it for AI.*

Workflow Library is an evolving collection of reusable workflow intelligence, human-AI designs, and AI-ready specifications.

It makes the knowledge behind how work gets done more visible, structured, and reusable—helping teams design, build, and evaluate AI-powered solutions with greater clarity.

## What's inside

The library is organized by industry and workflow.

Each workflow may document:

- **Activities and handoffs** — How work moves from beginning to end.
- **Decisions and judgment** — Where expertise and human oversight matter.
- **Knowledge and rules** — What information guides the work.
- **Exceptions** — What happens when the normal process doesn't apply.
- **Human-AI design** — Where people, AI, and deterministic tools should participate.
- **AI specifications** — How proposed capabilities should behave.
- **Evaluation** — How quality, reliability, and outcomes can be assessed.

## Our methodology

Point5to1 follows seven steps:

1. **Discover** — Understand the problem and the people doing the work.
2. **Map** — Capture activities, decisions, handoffs, and systems.
3. **Structure** — Organize context, rules, knowledge, and exceptions.
4. **Identify** — Determine where people, AI, and deterministic tools belong.
5. **Design** — Redesign the workflow and human-AI experience.
6. **Build** — Create experiments, prototypes, and working tools.
7. **Evaluate & Refine** — Test outcomes, learn, and improve.

## Workflow documentation

Individual workflows may contain:

| File | Purpose |
|---|---|
| `README.md` | Overview, scope, and status |
| `WORKFLOW.md` | Activities, decisions, and handoffs |
| `KNOWLEDGE.md` | Domain knowledge and business rules |
| `EXCEPTIONS.md` | Edge cases and escalation paths |
| `DECISIONS.md` | Decision models and design rationale |
| `DESIGN.md` | Human-AI workflow design |
| `AGENTS.md` | Agent roles and responsibilities |
| `EVALS.md` | Evaluation criteria and test scenarios |

Not every workflow requires every document.

## Relationship to AI Playground

[AI Playground](https://github.com/point5to1/ai-playground) is where we experiment, prototype, and learn.

Workflow Library is where useful workflow knowledge is organized and published for reuse.

A workflow specification in this library does not necessarily represent a deployed or production-ready solution.
